# 3D model assets

Only place models licensed for redistribution and web delivery in this folder.

Expected optional entry point: full-body.glb

For a complete anatomy atlas, prefer separately named mesh groups or assets for:
- skin / external body
- skeletal system
- muscular system
- cardiovascular, respiratory, digestive, nervous, urinary, lymphatic, endocrine, reproductive and sensory structures

Record the source, creator, exact license, attribution, version and modifications in an asset license note before publishing. Do not upload commercial anatomy assets unless their license explicitly allows redistribution.
